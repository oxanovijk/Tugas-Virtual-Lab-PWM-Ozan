# Parabola

## Platform
Web, seluruh perhitungan dan penyimpanan berjalan di browser.

## Stack
HTML5, CSS, JavaScript murni sesuai tugas. Dapat dibuka langsung tanpa build.

## Users and purpose
Mahasiswa TPB ITB mempelajari gerak parabola melalui eksperimen interaktif. Penilaian mencakup fitur HTML5, kreativitas CSS, dan kompleksitas JavaScript.

## Capabilities
Asumsi implementasi: model tanpa hambatan udara, input kecepatan/sudut/ketinggian/gravitasi, animasi dan vektor, hasil analitik, catatan percobaan, tantangan, ekspor CSV. Antarmuka Indonesia. Browser desktop dan mobile.

## Submission
Pengguna memerlukan source code, screenshot, link web/repository, serta deskripsi singkat. Penerbitan dan pengumpulan belum diminta.
